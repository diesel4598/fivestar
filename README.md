# خمس نجوم | مطعم شرقي فاخر (5 Stars Restaurant Platform)

منصة ويب عصرية وتفاعلية عالية التحويل لـ **"خمس نجوم | مطعم شرقي"**، متخصصة في الشاورما على الصاج، المشاوي على الفحم، الوجبات الكريسبي، العصائر الطبيعية 100%، والولائم الملكية العائلية.

---

## 🌟 أبرز المميزات (Key Features)

1. **تصميم فاخر وعصري (Dark Luxury Theme):**
   - ألوان داكنة ملكية (`#0E0E0E` و `#141414`) تُبرز صور الأطباق بدقة عالية.
   - لمسات ميتاليك ذهبية (`#D4AF37`) وكهرمانية مشوية (`#E85D04`).
   - خطوط طبوغرافية عربية أصيلة (`Cairo` و `Tajawal`).

2. **قائمة طعام تفاعلية ونظام طلب فوري:**
   - تصنيفات سريعة قابلة للتمرير والفرز (شاورما، مشاوي، سندويشات، كريسبي، مقبلات، عصائر).
   - شريط بحث لحظي لتصفية الوجبات بالاسم والمكونات.
   - نافذة تخصيص الوجبات (اختيار اللحم، الحجم، درجة الحرارة، والإضافات الخاصة).

3. **سلة طلبات وتحويل مباشر لواتساب (WhatsApp Ordering):**
   - سلة منزلقة مريحة تحسب الإجمالي الفرعي، رسوم التوصيل، وأكواد الخصم الترويجية تلقائياً.
   - إنشاء فاتورة رقمية منسقة باللغة العربية وإرسالها مباشرة لرقم المطعم المعتمد عبر واتساب بنقرة واحدة:
     **`+212 694-916737`**.

4. **لوحة تحكم وإدارة محمية برقم سري (PIN Protected Admin):**
   - دخول محمي برمز PIN سري مكون من 4 أرقام.
   - إمكانية تعديل وتغيير الرقم السري مباشرة وحفظه من داخل اللوحة.
   - تعديل أثمنة الوجبات والعصائر فورياً بالدرهم المغربي (`Dh`).
   - إضافة وجبات جديدة مع تحميل الصور من سطح المكتب (Drag & Drop) أو اختيار صور الاستوديو الاحترافية.
   - واجهة الزوار نظيفة 100% بدون أي أزرار تعديل عامة.

5. **دعم كامل للغتين والاتجاهين (Bilingual RTL / LTR):**
   - لغة عربية أصلية (`dir="rtl"`).
   - لغة فرنسية كاملة (`FR / LTR`).

## 📦 التثبيت والتشغيل المحلي (Getting Started)

# تشغيل بيئة التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
